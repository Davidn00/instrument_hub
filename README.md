# InstrumentHub

Platform for acquisition, processing, storage and analysis of instrumentation data.

## Overview

InstrumentHub is a Python-based platform designed to work with data generated by biomedical instruments and sensors.

The system is designed to support:

* Instrument and sensor simulation.
* Real hardware integration.
* Data acquisition.
* Signal processing.
* Data storage.
* Statistical analysis.
* Real-time monitoring.
* REST API access.
* Future data visualization.

## Architecture

The project follows a modular architecture:

API
 │
 ▼
Services
 │
 ├── Acquisition
 │
 ├── Processing
 │
 ├── Storage
 │
 └── Devices

The architecture intentionally separates HTTP/API concerns from acquisition, processing, device communication and persistence.

## Running the Application

Create and activate the virtual environment:

uv venv
source .venv/Scripts/activate

Install dependencies:
uv sync

Run the API:
uv run uvicorn app.main:app --reload

The API will be available at:
http://127.0.0.1:8000

Interactive API documentation:
http://127.0.0.1:8000/docs

## Running with Docker

Build the Docker image:
docker compose build

Start the application:
docker compose up -d

Check the running containers:
docker compose ps

The API will be available at:
http://localhost:8000

Health check:
http://localhost:8000/api/v1/health

Interactive API documentation:
http://localhost:8000/docs

View application logs:
docker compose logs -f api

Stop the application:
docker compose down
